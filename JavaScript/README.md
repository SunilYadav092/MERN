# MERN Learning Repository

A hands-on collection of beginner-to-intermediate web development examples and exercises. This repository builds the front-end foundation for the MERN stack through HTML, CSS, Bootstrap, and JavaScript.

> **Current scope:** This repository contains front-end learning materials. React, Express, Node.js, and MongoDB projects have not been added yet.

## Contents

| Folder | What you'll find |
| --- | --- |
| [`HTML`](HTML) | HTML fundamentals: page structure, text, lists, links, images, tables, forms, semantic elements, and `div`/`span`. |
| [`CSS`](CSS) | CSS examples covering selectors, box model, Flexbox, Grid, positioning, responsive design, colors, units, and pseudo-classes. |
| [`Bootstrap`](Bootstrap) | Bootstrap 5 examples for grids, buttons, forms, navigation, cards, utilities, responsive design, and layouts. |
| [`JavaScript`](JavaScript) | Topic-based JavaScript exercises with solutions, from fundamentals through async programming and ES6+ features. |

Each major front-end section includes concept notes to accompany the examples:

- [HTML concept notes](HTML/HTML_Concept.md)
- [CSS concept notes](CSS/CSS_Concept.md)
- [Bootstrap concept guide](Bootstrap/Bootstrap_Concept.md)
- [JavaScript exercise guide](JavaScript/EXERCISES_README.md)

## Getting started

### View HTML, CSS, and Bootstrap examples

No installation is required. Open an `.html` file in a browser, for example:

```text
HTML/01_Basic_Structure.html
CSS/03_Flexbox.html
Bootstrap/02_Grid_System.html
```

For a smoother workflow in VS Code, install the **Live Server** extension and choose **Open with Live Server**.

### Run JavaScript exercises

Install [Node.js](https://nodejs.org/) (version 18 or later recommended), then run an exercise from the repository root:

```bash
node JavaScript/01_Introduction_Exercises.js
```

Continue through the files in numerical order:

```bash
node JavaScript/02_Objects_and_Arrays_Exercises.js
node JavaScript/03_Functions_and_Scope_Exercises.js
# ...through 08_ES6_Plus_Exercises.js
```

Browser-focused topics such as DOM manipulation and event handling can also be copied into a browser's developer console or linked from an HTML page.

## Recommended learning path

1. Work through the HTML examples and notes.
2. Learn CSS fundamentals, then practice Flexbox, Grid, and responsive layouts.
3. Explore Bootstrap components and responsive utilities.
4. Complete the JavaScript exercises in numbered order.
5. Build small projects that combine all four areas before moving on to React and the back end.

## JavaScript topics

The JavaScript folder includes exercises on:

- Variables, data types, operators, conditions, and loops
- Arrays, objects, and destructuring
- Functions, scope, closures, callbacks, and recursion
- DOM manipulation and browser events
- Promises, `async`/`await`, Fetch, retry logic, debounce, and throttle
- Classes, inheritance, prototypes, and design patterns
- Modern ES6+ syntax and features

See the [complete exercise guide](JavaScript/EXERCISES_README.md) for details, suggested order, and practice tips.

## Prerequisites

- A modern web browser
- A code editor such as [Visual Studio Code](https://code.visualstudio.com/)
- [Node.js](https://nodejs.org/) for running JavaScript files in the terminal
