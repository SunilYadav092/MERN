## 📚 Contents

### HTML/
- **HTML_Concept.md** — Core concepts overview: elements, attributes, document structure, semantic tags, forms, and the DOM.
- **01_Basic_Structure.html** — The `<!DOCTYPE>`, `<html>`, `<head>`, `<body>` skeleton.
- **02_Text_Elements.html** — Headings, paragraphs, emphasis, quotes, sub/superscript.
- **03_Lists.html** — Unordered, ordered, nested, and description lists.
- **04_Links_and_Images.html** — Hyperlinks, anchor links, `mailto:`, and images.
- **05_Tables.html** — Rows, headers, cells, `colspan`/`rowspan`.
- **06_Forms.html** — Text/email/password inputs, radio, checkbox, select, textarea.
- **07_Semantic_Elements.html** — `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<aside>`, `<footer>`.
- **08_Div_and_Span.html** — Generic block vs. inline containers.

### CSS/
- **CSS_Concept.md** — Core concepts overview: selectors, the cascade, the box model, Flexbox, Grid, responsive design.
- **01_Selectors.html** — Element, class, ID, descendant, attribute, and pseudo-class selectors.
- **02_Box_Model.html** — Content, padding, border, margin, and `box-sizing`.
- **03_Flexbox.html** — `display: flex`, `justify-content`, `align-items`, `flex-grow`.
- **04_Grid.html** — `display: grid`, columns/rows, and named grid areas.
- **05_Positioning.html** — `static`, `relative`, `absolute`, `fixed`, `sticky`.
- **06_Responsive_Media_Queries.html** — `@media` breakpoints for responsive layouts.
- **07_Colors_and_Units.html** — Named/hex/rgb/rgba/hsl colors and px/%/em/rem/vw units.
- **08_Pseudo_Classes_and_Elements.html** — `:hover`, `:focus`, `:nth-child`, `::before`, `::after`, `::first-letter`.

> 💡 Each `.html` sample file is self-contained and can be opened directly in a browser to see the concept in action.
