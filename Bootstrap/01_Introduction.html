Bootstrap Basics & Setup

Bootstrap is a popular CSS framework for building responsive, mobile-first websites.

Info: Bootstrap uses a 12-column grid system for layouts.

Key Features:

  • Pre-built components (buttons, forms, cards, etc.)
  • Responsive grid system
  • Customizable color schemes
  • Mobile-first approach
  • JavaScript components
