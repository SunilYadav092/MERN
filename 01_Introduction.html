JavaScript Introduction & Basics

JavaScript is a versatile programming language that runs in web browsers and servers. It's used for interactive web pages, animations, and dynamic content.

1. What is JavaScript?

  • High-level, dynamic programming language
  • Runs in web browsers (client-side)
  • Can also run on servers (Node.js)
  • Object-oriented and functional programming support
  • Asynchronous capabilities (Promises, async/await)

2. Variables & Data Types

Variable Declaration

// Variables
let name = "John";      // Preferred (block-scoped)
const age = 25;         // Constant (unchangeable)
var city = "New York";  // Old way (function-scoped)

// Data Types
let number = 42;                    // Number
let text = "Hello";                 // String
let isStudent = true;               // Boolean
let skills = ["JS", "Python"];      // Array
let person = {name: "John", age: 25}; // Object
let nothing = null;                 // Null
